# Rules for AI agents

Read [docs/PRINCIPLES.md](docs/PRINCIPLES.md) before doing anything. It is the authority; this file is the short form.

1. **This is not a proof of concept.** Do not take the shortest path to something that mostly works. Every component is either the best known design, with evidence, or explicitly marked as not yet that.
2. **Research and design come before code.** Do not write implementation code for a component until its research is complete and a design covers it.
3. **This repository is public and holds only what is meant to be public**: source code, and documentation written for outside readers. Plans, working notes, research drafts, decision records, the register of open items and handoff documents belong in the project's private working repository. Do not add them here, and do not describe their contents in commit messages, pull requests or issues here.
4. **Do not settle the project owner's decisions for them.** Record your recommendation and ask.
5. **Claims need sources.** Say plainly when something is inference or unverified.
6. **Do not run, script or automate any commercial CAD product** unless the owner asks for that specific check.
7. **New source files carry the MPL-2.0 header notice** (Exhibit A of [LICENSE](LICENSE)).
