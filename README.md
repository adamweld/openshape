# OpenShape

OpenShape is an open-source, local-first mechanical CAD platform built for both human and AI use. The goal is a state-of-the-art parametric modeler, with its own geometric kernel where existing open-source components fall short, and an interface that lets an AI agent close the loop of design, simulated test and optimisation.

The project is in its research and design stage. There is no code yet, by intent.
